# System Scope

## In Scope
- Public school website
- Student registration/login
- Role-based access
- Student profiles
- Enrollment applications
- Requirements/document tracking
- Enrollment status tracking
- Registrar processing
- Programs/courses
- Subjects
- Sections
- Class schedules
- Teacher management
- Attendance
- Grades
- Student academic history
- Fee assessment
- Payment recording
- Receipts
- Announcements
- Notifications
- Reports
- Audit logs
- Backup/restore
- System settings

## Initially Out of Scope
These may be added later:
- Full online payment gateway integration
- Native Android/iOS application
- Biometric attendance
- AI-based academic analytics
- Parent portal
- Multi-school SaaS deployment
- Advanced accounting/general ledger
- Automated government integrations

## Scope Rule
Do not add out-of-scope features during implementation unless explicitly approved.
