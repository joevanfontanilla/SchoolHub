# Registrar Module

## Dashboard
- New applications
- Pending review
- Incomplete requirements
- Approved applications
- Enrolled students
- Enrollment statistics

## Functions
- Application queue
- Student records
- Requirement verification
- Enrollment approval
- Enrollment correction requests
- Program management
- Subject management
- Section management
- Class assignment
- Enrollment history
- Registrar reports

## Application Review
Registrar should be able to see:
- Student information
- Academic selection
- Uploaded requirements
- Previous enrollment history
- Review timeline
- Remarks
- Current status

## Acceptance
A registrar action must update the application status and create an audit/event record.
